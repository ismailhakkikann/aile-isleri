Privacy Policy

Last updated: November 10, 2026

"Aile İşleri Upload" is a private tool used only by the owner of the Aile İşleri channel (Ismail Kan) to upload his own animated videos to his own TikTok, Instagram and YouTube accounts.

Data we access

When the owner connects a TikTok account, the tool receives an access token and basic profile information (open id, display name, avatar) through TikTok Login Kit, and uses the Content Posting API only to upload videos the owner created.

How data is used and stored

Tokens are stored only on the owner's own computer and are used only to upload the owner's videos. No data is sold, shared with third parties, or used for advertising. No data from other TikTok users is collected.

Deletion

The owner can revoke access at any time in TikTok settings (Security and permissions, Apps). Revoking access makes the stored token useless; the local file can be deleted at any time.
